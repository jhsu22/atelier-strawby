# Local typefaces

Geist (headings and the wordmark), Newsreader (italic notes), Inter (interface), and JetBrains Mono (metadata) are self-hosted WOFF2 variable fonts. Latin and Latin Extended subsets were downloaded from the official Google Fonts CSS service. Browsing the application does not request remote fonts.

Sources: [Geist](https://github.com/google/fonts/tree/main/ofl/geist), [Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader), [Inter](https://github.com/google/fonts/tree/main/ofl/inter), [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono).

Their SIL Open Font License notices are included alongside the files. The CSS font declarations preserve the original subset Unicode ranges. Other scripts use system fallbacks.
